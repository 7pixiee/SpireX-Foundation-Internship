# Soft Life Expense Tracker

A simple expense tracker made with HTML, CSS and vanilla JavaScript.

## Features
- Add an expense with a name, amount, category and date
- View recorded expenses
- Delete expenses
- Automatically calculate the total in Indian Rupees (INR)
- Save expenses in the browser using localStorage
- Responsive layout for desktop and mobile

No installation or build commands are needed. Your expenses are saved in the browser where you open the website.
