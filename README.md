# FORME - Shopping Cart
### A responsive shopping cart website built with HTML, CSS and vanilla JavaScript.
## Features
- Product listing with category filters and search
- Add products to the bag
- Increase or decrease item quantities
- Remove individual items or clear the bag
- Automatic subtotal, shipping and total calculation
- Complimentary shipping on orders over ₹2,500
- Dark and light themes
- Cart and theme preferences saved in localStorage
- Responsive layout for desktop, tablet and mobile
