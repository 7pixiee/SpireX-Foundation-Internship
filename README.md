## About this repository

Every task has its own folder, named `task-` followed by the task number. Each folder holds a complete, working project that can be opened on its own.

Browse the folders above to see the tasks. They are listed in order, starting from `task-01`.

## Tech used

- **HTML5** for structure and semantic markup
- **CSS3** for layout, responsive design and animations
- **Vanilla JavaScript** for interactivity, form validation and working with the DOM

The projects are built without frameworks. Some of them also use `localStorage` to remember data in the browser and fetch data from public APIs.

## Running a project

No installation or build step is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/7pixiee/SpireX-Foundation-Internship.git
   ```
2. Open the folder of the task you want to see.
3. Open its `index.html` file in a browser.

Some projects load fonts or images from the internet, so they look best with a connection.

## Folder structure

Most tasks follow the same simple layout:

```
task-XX/

└── script.js
```
