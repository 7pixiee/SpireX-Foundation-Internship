# Northstar Medical Centre

A responsive hospital appointment website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop and mobile navigation
- Light and dark themes, with the selected theme saved in local storage
- Medical services section
- Doctor directory with search and specialty filtering
- Appointment request form with browser validation
- Doctor and department selection helpers
- Appointment requests saved locally in the browser
- Responsive layout for mobile, tablet and desktop

## Important note
This is a frontend demonstration. Appointment requests are stored only in the visitors browser using local storage. They are not sent to a hospital, and the listed clinic, doctors, contact details and availability are sample content. A real booking service requires a secure backend, database and clinic side confirmation workflow.
